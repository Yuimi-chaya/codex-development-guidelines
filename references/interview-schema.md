# First-Adoption Question Bank

The canonical [question bank](../skills/adopt-agent-policy/references/interview.md) lives inside the independently installable adoption Skill.

Its 31 stable question IDs are topics, not a mandatory 31-turn script. First adoption and deliberate updates resolve the selected questions using existing explicit answers where available. Ordinary threads do not run this interview. Unasked questions neither grant permission nor disable runtime protection.
