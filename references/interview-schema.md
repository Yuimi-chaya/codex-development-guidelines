# Configuration Decision Checklist

The canonical [decision checklist](../skills/adopt-agent-policy/references/interview.md) lives inside the independently installable configuration Skill.

The checklist groups scope/language, environment/recovery, models/delegation, resources/media, proactive interaction, and conflicts/write scope. Finish accessible discovery and relevant evidence checks first, recommend a configuration, and collect unresolved choices together. Reuse explicit answers and follow up only at real dependencies. Ordinary threads do not run setup. Unasked questions neither grant permission nor disable runtime protection.
