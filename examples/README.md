# Examples

Files in this directory are concrete, environment-specific examples. They are not portable defaults and must not be copied into a user's `AGENTS.md` without the guided interview and semantic merge workflow.

- [`AGENTS.windows-powershell-zh-CN.md`](AGENTS.windows-powershell-zh-CN.md): a maintained Simplified Chinese Windows/PowerShell profile example. It intentionally contains user-selected local conventions, including concrete subagent routing; treat those values as examples rather than repository requirements.
