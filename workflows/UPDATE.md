# Policy Updates

The canonical [update workflow](../skills/adopt-agent-policy/references/update.md) is bundled with the adoption Skill.

Only deliberate configuration or source updates trigger it, not a new coding thread. Inspect affected facts first, compare actual behavior and local customizations, and collect changed decisions with recommendations. Installed files do not require source IDs or an old record. Never treat an upstream revision as overwrite authority or introduce maintenance tags into runtime instructions.
