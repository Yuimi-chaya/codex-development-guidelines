# Configure Codex Instructions

The canonical [adoption workflow](../skills/adopt-agent-policy/references/adoption.md) is bundled with [adopt-agent-policy](../skills/adopt-agent-policy/SKILL.md) so installation does not break its references.

An installation request starts read-only environment/configuration/model discovery and relevant public-source checks. Recommend a complete configuration and collect unresolved preferences together. Default to the actual Codex-home `AGENTS.md`; honor explicit project targets and inspect overrides. The Skill bundles clean bilingual policy assets, so no extra source checkout or rule selection is required.

Reuse preferences, merge existing instructions semantically, and keep maintenance IDs out of the installed file. Show the concrete diff and recovery plan, use existing explicit authority, and resolve missing approval through a permitted channel. Optional operations have named scopes that can be decided together. Ordinary threads and read-only reviews do not restart setup.
