# First Adoption

The canonical [adoption workflow](../skills/adopt-agent-policy/references/adoption.md) is bundled with [adopt-agent-policy](../skills/adopt-agent-policy/SKILL.md) so installation does not break its references.

Use it only for deliberate first adoption in a user/project scope. Ordinary new threads use the already adopted runtime instructions, without repeating the interview. Read-only reviews remain read-only. Reuse known preferences, compare semantically, show the final diff and recovery plan, and obtain separate write approval.
